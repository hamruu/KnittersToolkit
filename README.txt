This is a project by which I develop tools to do the maths for knitting hobbyists to make their lives easier.

A knitter I know knits on four needles in order to have all stitches in a round. 

You can reasonably have between 7 and 20 stitches on a needle.

If odd, reduce one row to make it even.
Per reduction step, reduce once and then do n/2-2 rows.
